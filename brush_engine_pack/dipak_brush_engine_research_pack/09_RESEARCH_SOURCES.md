# 09 — Research Sources

Primary/official project sources used in the research:

- p5.brush official GitHub repository — natural brushes, standalone WebGL2 build, custom/image tips, pressure, splines, vector fields.
  https://github.com/acamposuribe/p5.brush

- perfect-freehand official GitHub repository — pressure-sensitive stroke outline geometry.
  https://github.com/steveruizok/perfect-freehand

- Paper.js Path reference — path length, point/tangent/normal sampling, smoothing.
  https://paperjs.org/reference/path/

- PixiJS v8 renderers, filters and mesh docs — WebGL/WebGPU rendering, custom shaders, filters, meshes.
  https://pixijs.com/8.x/guides/components/renderers
  https://pixijs.com/8.x/guides/components/filters
  https://pixijs.com/8.x/guides/components/scene-objects/mesh

- GSAP DrawSVG docs — SVG stroke reveal through dasharray/dashoffset.
  https://gsap.com/docs/v3/Plugins/DrawSVGPlugin/

- W3C Filter Effects Level 1 — feDisplacementMap / feTurbulence behavior.
  https://www.w3.org/TR/filter-effects-1/
