# ACT 5 — WHAT I TALK ABOUT

## Verified subject territory

The project structure already supplies these categories:

- Sales
- Buyer Psychology
- Communication
- Personal Branding
- AI
- Entrepreneurship
- Startups
- Public Speaking

These are safe to use as topic labels.

## Design concept

Do not use a standard 2×4 icon card grid.

Create an **editorial topic index**.

### Desktop option A — giant list

```text
05 / SUBJECTS

WHAT I
TALK ABOUT.

01  SALES
02  BUYER PSYCHOLOGY
03  COMMUNICATION
04  PERSONAL BRANDING
05  AI
06  ENTREPRENEURSHIP
07  STARTUPS
08  PUBLIC SPEAKING
```

Each row spans the viewport.

Hover:
- number becomes gold
- row shifts 4px
- tiny directional arrow appears
- no background card

### Desktop option B — two-column editorial index

Left:
- large section title

Right:
- 8 topic rows in two columns

Option A is stronger and more differentiated.

## Scroll behavior

This section should not be a long cinematic scene.

Use a short sticky/scroll sequence where each topic row becomes fully opaque as it crosses a horizontal reading line.

Do not animate them flying from different directions.

## Shared motif from Act 4

The Act 4 manifesto rule becomes the **reading axis**.

As the visitor enters Act 5:
- rule moves to the left edge of topic labels
- topic rows reveal against it

## Fine-pointer interaction

Optional:
- row underline extends
- number color changes
- cursor proximity causes max 2px x movement

## Mobile

Simple numbered list.

Typography:
- 27–34px topic labels
- no icons
- no horizontal scrolling
- `Buyer Psychology`, `Personal Branding`, `Public Speaking` may wrap intentionally

## Links

If category pages are not ready, rows can be non-link visual elements initially.

Do not create dead `href="#"` links.
